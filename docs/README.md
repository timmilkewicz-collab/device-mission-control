# Docs Map

This repo now treats documentation in two buckets:

- `docs/ai/` = active AI role, memory, decision, handoff, and runbook docs
- `docs/base44/` = active operator docs that support the current mission-control and Base44 workflow
- `docs/archive/` = historical, research, or one-off reference material that should not drive current build decisions by default

If a document is still shaping the live system, it belongs in an active folder. If it is useful context but not a current source of truth, it belongs under archive.

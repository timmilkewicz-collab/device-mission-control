# HOQS Image Sources for Base44

## Purpose

Base44 should use this file to avoid unrelated or generic imagery.

The site should pull from real HOQS-related visuals first.

Do not use:

- generic stock speaker photos
- AI-generated lifestyle imagery
- unrelated workshop scenes
- glossy ecommerce placeholders that do not match HOQS

If a real image is not available for a section, use layout, typography, spacing, texture, or simple graphic treatment instead of fake filler images.

## Primary Source Site

- HOQS Australia home: `https://www.hoqs.com.au/`
- HOQS Australia projects: `https://www.hoqs.com.au/projects`
- HOQS Australia drivers: `https://www.hoqs.com.au/hoqs-drivers`
- HOQS Australia recommended builders: `https://www.hoqs.com.au/recommended-builders`

## Recommended Usage

Use these images as:

- homepage reference imagery
- section backgrounds
- project thumbnails
- drivers section visuals
- builder/community visuals

These are real HOQS-hosted image URLs found on the Australia site.

## Image Handling Instruction for Base44

When building the site:

- prefer these HOQS image sources first
- keep imagery closely tied to real builds, drivers, projects, and community
- use project imagery in project-related sections
- use drivers imagery in driver-related sections
- use builder/community imagery in builder and about/community sections

If hotlinking these assets is not appropriate in the final build, still use them as the visual reference set for replacement with approved local copies.

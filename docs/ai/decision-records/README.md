# Decision Records

Use this folder for meaningful architecture, workflow, deployment, or data-flow decisions.

Filename format:

`YYYY-MM-DD-short-title.md`

Template:

```markdown
# Decision: Short Title

Date: YYYY-MM-DD

Status: accepted

## Context

What forced this decision?

## Decision

What did we choose?

## Consequences

What gets easier, what gets harder, and what should future agents remember?
```

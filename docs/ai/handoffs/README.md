# Handoffs

Use this folder when substantial work leaves context the next agent should not rediscover.

Filename format:

`YYYY-MM-DD-short-topic.md`

Template:

```markdown
# Handoff: Short Topic

Date: YYYY-MM-DD

Active role: Builder

## What Changed

Short factual summary.

## Verification

Commands run and results.

## Next Useful Step

One or two concrete next moves.

## Watchouts

Risks, stale assumptions, or known gaps.
```
